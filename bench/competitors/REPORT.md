## Method

1. Each tool runs on a disposable clone of a corpus fixture (see `tools.toml` for the exact argv; nothing is invented here — unrunnable tools stay `pending`).
2. Wall time is measured around the tool process; peak RSS and API-call counts attach with the first networked measurement run (needs `mitmproxy` recording, M0.3 follow-up).
3. Marketing claims are only made from these numbers, never from the §1.1 table.
